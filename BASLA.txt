APARTMANIM v1.2 — iPHONE 16 PRO MAX EKRAN / ZOOM DÜZELTMESİ
===========================================================

Bu paket mevcut GitHub Pages uygulamasına yönelik GÖRSEL güncellemedir.

GÜNCELLENEN DOSYALAR
- styles.css : iPhone Safari form otomatik yakınlaştırmasını azaltan 16px giriş yazıları;
               tek sütun mobil formlar; Dynamic Island/alt çubuk güvenli alanları.
- sw.js     : önbellek sürümü yükseltildi; yalnızca Apartmanım'a ait eski
               önbellekler temizlenir (aynı GitHub hesabındaki ALP FIT
               gibi başka uygulamaların önbelleklerine dokunmaz).

NELERE DOKUNULMUYOR?
- app.js, config.js, Supabase SQL dosyaları, aidat/ödeme verileri.
- Aidat ödemesi geri alma (v1.1) özelliği aynen kalır.
- iPhone'un erişilebilirlik için iki parmakla yakınlaştırma özelliği kapatılmadı.

KURULUM
1. Bu ZIP'i bilgisayarda aç.
2. GitHub > alpdemirkapu/apartmanim deposunu aç.
3. Add file > Upload files yoluna gir.
4. YALNIZCA styles.css ve sw.js dosyalarını deponun ana dizinine yükle.
   Mevcut dosyaların üzerine güncellemeyi uygula (Commit changes).
5. GitHub Pages'in yeni değişikliği yayınlamasının ardından:
   - iPhone'da ana ekrandaki Apartmanım uygulamasını uygulama değiştiriciden
     tamamen kapatıp yeniden aç.
   - Hâlâ eski tasarım görünüyorsa Safari'den aynı web adresini açıp
     sayfayı yenile, ardından ana ekran uygulamasını tekrar aç.
6. Aidat ödeme / gelir-gider formlarına dokunup ekranın otomatik zoom yapıp
   yapmadığını kontrol et.

NOT: Veritabanını tekrar kurma, SQL çalıştırma veya ana ekran simgesini
silip tekrar ekleme gerekmiyor. iPhone'un sistemdeki Ekran Yakınlaştırma
ayarını bu web güncellemesi değiştiremez.
